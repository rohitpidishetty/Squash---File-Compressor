# Squash

A high-performance Java compression library designed for efficient file compression and decompression using a hybrid **LZ77/LZSS + Huffman Coding** pipeline.

Squash focuses on providing a lightweight, extensible, and streaming-oriented architecture capable of compressing large files while maintaining fast execution speeds and minimal memory overhead.

---
#### Usage

```bash
java Squash -squash <file-path | folder> <squash-as-name> <output-path>
java Squash -desquash <squash-file> <output-path>
```

#### Example

```bash
java Squash -squash "C:\\Users\\<YourName>\\Pictures\\Screenshots 1\\Image.png" squashed "C:\\Users\\<YourName>\\Desktop"
java Squash -desquash "C:\\Users\\<YourName>\\OneDrive\\Desktop\\test\\pic.sq" "C:\\Users\\<YourName>\\OneDrive\\Desktop\\test"
     
```

# Compression Pipeline

Squash combines two lossless compression algorithms to maximize compression efficiency while preserving the original file exactly.

## 1. LZ77 / LZSS Encoding

The first stage scans the incoming byte stream and searches for repeated sequences within a sliding window.

Instead of repeatedly storing identical data, the encoder replaces duplicate sequences with compact references containing:

- Offset
- Match Length
- Literal Byte (when required)

This stage significantly reduces redundancy before entropy coding.

---

## 2. Huffman Encoding

The token stream generated by the LZ77/LZSS encoder is compressed further using Huffman Coding.

A Huffman tree is constructed based on symbol frequencies.

- Frequently occurring symbols receive shorter binary codes.
- Rare symbols receive longer binary codes.

This stage reduces the overall compressed size without any loss of information.

---

# Processing Strategy

Large files are processed incrementally instead of loading the complete file into memory.

Each compression cycle performs:

1. Read a chunk from disk.
2. Compress using LZ77/LZSS.
3. Encode using Huffman Coding.
4. Write compressed output.
5. Repeat until the end of the file.

This design enables Squash to efficiently process files of virtually any size while maintaining consistent memory usage.

# API Documentation

## Compress a File

```java
File target = new File("example.txt");

try (DataOutputStream dos =
         new DataOutputStream(
             new BufferedOutputStream(
                 new FileOutputStream("example.squash")))) {

    FileSquasher.compress(
        target,
        false,
        enums.Files.FILE,
        dos
    );
}
```

---

## Extract a File

```java
File compressed = new File("example.squash");

FileExtractor.extract(compressed);
```

---

## Stream Compression

```java
LZ77Encoder.encodeStream(
    buffer,
    bytesRead,
    debugMode,
    dataOutputStream
);
```

# API Overview

| Class            | Description                         |
| ---------------- | ----------------------------------- |
| `FileSquasher`   | Compresses files into Squash format |
| `FileExtractor`  | Restores compressed files           |
| `LZ77Encoder`    | Performs dictionary-based encoding  |
| `LZ77Decoder`    | Reconstructs original data          |
| `HuffmanEncoder` | Performs entropy encoding           |
| `HuffmanDecoder` | Restores encoded symbols            |

Meaningful exceptions are propagated to simplify debugging and integration.
